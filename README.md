# ЛР1. Галактики: определение расстояния по сверхновым типа Ia

Страницы по макетам Figma: «Лента», «Добавление», «Плитка».
Данные хранятся в коллекции `data.py` (без базы данных), фото и видео — в MinIO (бакет `galaxies.media`).

## Запуск

```bash
docker compose up -d
pip install -r requirements.txt
uvicorn main:app --reload --port 8001
```

| Страница | Адрес |
|---|---|
| Плитка (с фильтром по расстоянию) | http://127.0.0.1:8001 |
| Лента | http://127.0.0.1:8001/feed/1 |
| Добавление (черновик) | http://127.0.0.1:8001/add |
| MinIO | http://localhost:9001 (admin / password123) |

База данных, ORM, лайки и удаление — в ветке `Database_Backend` (ЛР2).
